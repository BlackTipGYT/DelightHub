# DelightHub starter website

A free, responsive starter site for an independent Delightex EDU community hub.

## Included
- Responsive landing page
- Project showcase with search and category filter
- Tutorial links
- RGB-to-hex colour converter
- Community section and independence disclaimer

## Edit before publishing
1. Replace the example project descriptions and `https://edu.delightex.com/` links with real project URLs.
2. Add your preferred name/logo and any extra tutorials.
3. Keep the disclaimer that this is an independent, unofficial community project.
4. Do not add personal details, passwords, or private data.

## Publish for free with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a **public** repository, for example `delighthub`.
3. Upload `index.html` to the top level of the repository.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/(root)`, and save.
6. Wait for deployment, then open the URL shown in Settings → Pages.

GitHub Pages sites are public on the internet. Do not put private information in the repository.
